# 🌙 RB - Universal Calendar App (2014 - 2060)

**RB** is a modern, responsive, and feature-rich Web & Progressive Web App (PWA) designed to provide accurate Gregorian, Bengali (BS), and Hijri (AH) calendar dates along with live international public holiday updates for any country worldwide.

Developed by **By Rafsan**.

---

## ✨ Features

- **🌐 Multi-Calendar Support (Bangladesh Special):**
  - Displays **Gregorian (English)**, **Bengali (BS)**, and **Hijri (AH)** dates simultaneously in the same day cell for Bangladesh.
  - Standard clean layout for all other selected countries.

- **📅 Wide Year Range (2014 – 2060):**
  - Easily switch between any year from 2014 to 2060.
  - Automatically syncs current real-time date and time based on the user's selected country.

- **🗣️ Dynamic Multi-Language Support (11 Popular Languages):**
  - Full translation support including Month Names, Weekdays, Controls, Labels, and Headers.
  - **Supported Languages:** English, Bengali (বাংলা), Spanish (Español), Hindi (हिन्दी), Arabic (العربية), Persian (ফার্সী), French (Français), Chinese (中文), Russian (Русский), German (Deutsch), Portuguese (Português).
  - *Note: App title "RB" remains consistent across all language selections.*

- **🎉 Auto-Updating Public Holidays (Live API):**
  - Fetches real-time, official national holidays using the open-source `date.nager.at` Public Holidays API.
  - Automatically updates holiday data when changing the year or country.

- **📊 Annual Holidays Chart:**
  - Separate dedicated tab displaying a comprehensive list of all national holidays for the selected country and year.

- **🔍 Global Country Search:**
  - Interactive search bar to look up and select any country code (e.g., BD, US, GB, IN, SA, AE, CA, AU, JP, DE).

- **🌌 Glassmorphism & Cosmic Dark Theme:**
  - Stunning UI featuring ambient radial glows, frosted glass cards, vibrant date accents, and responsive grids.

- **📱 Offline & Mobile Ready (PWA Compatible):**
  - Fully responsive design optimized for mobile phones, tablets, and desktop computers.
  - Works online for live API updates and caches data for offline use.
